# Dependencies, assets and licensing

## Runtime dependencies

- **Three.js** — WebGL rendering, GLTF loading, meshopt decoding, geometry and skeleton helpers (MIT).
- **Express 5** — same-origin HTTP API and production static hosting (MIT).
- **ws** — WebSocket transport (MIT).
- **Zod** — wire and API input validation (MIT).
- **bcryptjs** — established password hashing (MIT).
- **Helmet / express-rate-limit / cookie-parser** — HTTP hardening and sessions (MIT).
- **Node.js 22+** — local SQLite adapter and server runtime.

Development uses Vite, TypeScript, Vitest, tsx and Supertest. Review package licenses and lockfile during release preparation; this document is not a substitute for generated third-party notices.

## Game assets in this slice

The district geometry, signage, road/wall/roof textures, icons, UI, rain and procedural audio are generated by original source code in this repository. No map tiles, photographs, music, voice or sound recordings are bundled.

Realistic citizens and vehicles are **locally bundled CC0 models**, not remote hotlinks. Their source, modifications and hashes are recorded in [`public/assets/asset-manifest.json`](../public/assets/asset-manifest.json), with readable notices in [`public/assets/CREDITS.md`](../public/assets/CREDITS.md).

### Citizens and animation

- MakeHuman Community system meshes, clothing, hair and textures: **CC0 1.0** ([upstream asset pack and license](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)).
- Quaternius Universal Animation Library locomotion: **CC0 1.0** ([upstream pack](https://quaternius.itch.io/universal-animation-library)).
- The bundled derivatives use the fully clothed `civ_m1`/`civ_f1` meshes with dark-skin textures from `civ_m2`/`civ_f2`. The runtime normalizes their different source heights, clones skeletons safely, cross-fades idle/walk/sprint, layers the wave emote, and applies saved skin/clothing colors. Separate skin, eye, brow, eyelash, hair and fabric material roles retain their textures; a low-intensity texture-backed readability fill works with the night lighting rather than replacing facial detail with flat emissive colors.
- Two cached templates serve all citizens. Original procedural people remain available if a model fails to load.

### Vehicles

- Unbranded Innerscene sedan, hatchback and passenger van: **CC0 1.0** ([sedan](https://www.innerscene.com/tools/library/3d-parts/white-four-door-sedan-1f271353), [hatchback](https://www.innerscene.com/tools/library/3d-parts/silver-five-door-compact-hatchback-6bf4a878), [van](https://www.innerscene.com/tools/library/3d-parts/passenger-van-with-side-windows-474dd4a2), [library terms](https://www.innerscene.com/tools/library/terms)).
- Taxi-LIB retains separate wheel assemblies, applies cooperative/private paint, adds taxi signs and plates, normalizes real-world scale, and connects steering/rolling to existing handling.
- Three cached templates serve legacy player and traffic vehicles. Original procedural vehicles remain available if a model fails to load. The Mesurado Aero and Farmington Cross use separate original Taxi-LIB procedural body lofts, glazing, LEDs and alloy-wheel geometry; no third-party modern-car asset is bundled.

### Provenance and reproduction

The reviewed GLB distribution mirror is `mohammedemara48-code/police-command`, pinned to commit `db6a7ba31e4071db4aa7ec5d7ea0349d1343bd93`. Upstream CC0 licensing is documented independently above; permission is not inferred from the mirror's application code license.

```bash
# Optional maintainer rebuild; not needed to install, develop or run the game.
python3 scripts/prepare-visual-assets.py
```

The script uses only Python's standard library, verifies every reviewed source SHA-256, replaces only the citizen skin image buffer, and writes deterministic local GLBs plus the output manifest. The source models are not fetched at application runtime. Vehicle and citizen GLBs use meshopt compression and embedded WebP textures; Three.js's decoder and the player's browser handle them locally.

## Verification boundary

Asset structure, hashes, clips, materials and wheel nodes are checked in automated tests. API/smoke tests verify that gameplay remains functional. These checks do **not** replace browser rendering and visual review on target GPUs; no claim of browser visual verification is made without that review.

The Liberian-inspired flag accents are used respectfully as a national visual reference; Taxi-LIB is not an official government product. Place and business labels marked fictional must not be represented as verified infrastructure.

## Future asset rules

- Store author, source URL, license, modification and attribution in the asset manifest.
- Prefer original or appropriately licensed PBR materials, performance-captured animation and recorded Liberian ambience with documented consent/permits.
- Do not hotlink map tiles or redistribute restricted geographic data.
- Treat user uploads as untrusted; scan, type/size limit and store outside the executable public tree.
- Do not integrate proximity voice until a real transport/provider and privacy/moderation design are operational.
